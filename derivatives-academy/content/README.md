# 內容稿（content/）

這裡放每個商品的 Markdown 內容稿，是商品頁的**文字來源**。流程是「先寫內容稿 → 擁有者確認 → 再做 `products/<slug>/index.html`」。

- 新商品：複製 `templates/content-template.md` 為 `content/<slug>.md`。
- 開頭欄位格式、七個標題、公式／提示框／表格寫法，都以 `templates/content-template.md` 為準。
- 修改金融內容時，Markdown 與 HTML 要同步更新，並在 `log.md` 記錄。
- 所有示例皆為教學假設；不得使用未公開銀行報價、內部文件、客戶資料或公司名稱。
