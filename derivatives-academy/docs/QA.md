# QA 驗收清單｜Derivatives Academy

> **使用方式：** 本檔是每次新增商品、修改功能或發布版本時都可重新使用的**人工／自動驗收模板**，以下未勾選的 `[ ]` 代表**這份模板尚未為當次版本填寫**，不代表先前版本從未通過檢查。已執行的測試結果、執行日期、受測範圍及尚未完成的人工審查，以 [`../log.md`](../log.md) 的實際紀錄為準。
>
> **紀錄原則：** `tests.html` 左側的損益測試為瀏覽器即時計算；右側「檢查紀錄」為有日期的**歷史快照**，不是網站每次更新後的自動驗收。只有重新執行相對應的 Node、Chrome 及人工檢查，才能更新其日期和通過範圍。未重新驗收時應保留舊結果並清楚標示快照日期；不可將已測試的舊版結果冒充新版結果。

## B. 人工檢查：不可謊稱「自動驗證」

- [ ] 手機 375px：首頁、商品、課程與模擬器沒有整頁水平捲動（表格內可橫向捲動）。
- [ ] 平板 768px 與桌面 1280px：標題、卡片、圖表可閱讀。
- [ ] 網頁首頁上線卡片可以點到正確頁；規劃中卡片沒有假連結。
- [ ] 商品頁七段內容與 `content/<slug>.md` 一致。
- [ ] 所有內部連結、按鈕、學習路徑與頁腳導覽可操作。
- [ ] Payoff Lab 換四種部位時，曲線與顯示的淨損益同步改變。
- [ ] 金融公式方向、報價幣別、單位、期限、情境、風險說明由**本人審查**。
- [ ] DCI 描述到期可能換幣、原始幣別的本金損失及發行人信用風險。
- [ ] 網頁含「教學用途，不構成投資建議」，沒有內部報價或客戶資料。
- [ ] **正式 GitHub Pages URL** 實際打開上述頁面；不可僅看本機成果。

## C. 公式核心案例（每次改 `assets/payoff.js` 必測）

假設歐式、到期結算、每單位標的、標的價 ≥ 0、無費用與利息。

| Position | Strike | Premium | Terminal | Net P&L |
|---|---:|---:|---:|---:|
| Long Call | 100 | 5 | 110 | +5 |
| Short Call | 100 | 5 | 110 | −5 |
| Long Put | 100 | 5 | 90 | +5 |
| Short Put | 100 | 5 | 90 | −5 |
| Long Call (OTM) | 100 | 5 | 90 | −5 |
| Long Put (OTM) | 100 | 5 | 110 | −5 |
| Long Call (BE) | 100 | 5 | 105 | 0 |
| Short Put (S=0) | 100 | 5 | 0 | −95 |

> 此測試僅覆蓋通用選擇權到期淨損益公式，不足以替代個別 FX Option 或 DCI 契約條款的金融專業驗證。
