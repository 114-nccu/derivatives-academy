06｜Applied Derivatives｜外匯避險實務

把工具選擇放回企業現金流：辨識風險、比較 Forward／Option、檢查剩餘暴露與執行成本。

01 / FRAMEWORK

先找現金流，再選商品

交易室或企業避險最先問的不是「會不會上漲」，而是：誰、在何時、需要支付或收到什麼幣別、金額有多確定？

評估衍生商品時，建議先整理五項：幣別與報價方向 → 受影響的現金流 → 金額與期限 → 風險容忍度 → 合約及流動性限制。同樣一個美元走強情境，進口商美元應付和出口商美元應收的方向可能完全不同。

本章僅用教學假設做比較，不提供即時外匯報價、交易建議或特定商品適合性判斷。

02 / CHOICES

Forward、Option、Swap 各解什麼問題？

工具 主要目的 應注意的限制
FX Forward 事先確定未來特定日期換匯率 有交割義務，也可能放棄有利方向
FX Vanilla Option 支付 Premium 換取履約權利 權利金成本、到期／履約條款及波動率
FX Swap 安排近端與遠端兩次反向換匯、管理幣別資金期限 必須備妥遠端交割幣別，存在資金與 MTM 風險
DCI 結構型投資／收益與條件式到期換匯 可能轉成非原始幣別、承擔本金及發行人風險

這些工具不是同一目的的完美替代品。DCI 不是標準的企業美元應付款避險工具，不應只因潛在票息就用來取代原本的風險管理策略。

03 / EXAMPLE

美元進口商：鎖定成本或保留有利方向

假設三個月後要支付 USD 100,000 貨款。為比較概念，假設三個月 USD Forward 匯率 USD/TWD 32.20，同期限 USD Call（買 USD／賣 TWD）履約匯率 32.20、權利金 TWD 0.30／USD，且到期以 USD/TWD 即期匯率作為履約比較。三項均為獨立教學假設，不是由同一套波動率／利差模型推導的無套利市場報價。

遠期換匯成本 = USD 100,000 × 32.20 = TWD 3,220,000
買 USD Call 的簡化到期換匯成本 = USD 100,000 × [min(Sₜ, 32.20) + 0.30]
假設到期即期 USD/TWD Forward 支付 TWD Option 方案：換匯＋權利金 TWD
31.00 3,220,000 3,130,000（以即期買美元）
33.00 3,220,000 3,250,000（執行 Call）

Option 方案的 Premium 通常在建立部位時支付；表格將其名目加總方便比較，未折現權利金至同一時點，也未計費用、匯率波動對權利金幣別的影響及實際交割安排。因此這不是嚴格同一估值日的 P&L 比較。

04 / WORKFLOW

交易室風險管理檢核

實務上，報價、簽約與後續管理不能只看公式。應再次確認：

  1. 曝險真實性： 是否確有 USD 應付？金額、付款日與訂單取消概率是多少？
  2. 比價單位： FX 報價方向、Premium 幣別、點數、名目本金及交易費用是否相同？
  3. 流動性及信用： 授信額度、擔保需求、交易對手違約、交割時間差。
  4. 情境及壓力測試： 美元升值、貶值、付款延後、企業收入下修時各會怎樣？
  5. 持續監控： 到期提醒、財務報表／避險會計（如適用）、提前結清價格與風險歸屬。

避險成功應定義為相對於企業真實風險目標減少不確定性，而不是每筆衍生商品單獨都有正 P&L。

05 / PRACTICE

實務問答與下一步

Q1：Option 方案在 USD/TWD 33.00 時，比 Forward 更貴，因此 Option 一定比較差嗎？

不能只看單一情境。 Option 的成本來自保留有利方向的權利，還需要比較整個分配、尾端風險與 Premium 的資金成本。

Q2：公司付款日延後，原 Forward 就可以不交割嗎？

不可以自行取消。 應核對契約並協調展期／平倉，可能有 MTM 損益與交易費用。

Q3：我能直接用 FX Option 的到期 Payoff Lab 計算企業完整避險成效嗎？

不行。Payoff Lab 只計標準到期選擇權淨損益，未納入實際採購現金流、融資成本、契約交割與會計處理。
