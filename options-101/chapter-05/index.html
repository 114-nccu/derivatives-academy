05｜Option Strategies｜組合策略與避險

從 Protective Put、Covered Call、Bull Call Spread 到 Collar，看懂保護成本與獲利上限。

Foundations約 12 分鐘教學案例均為假設

01 / PURPOSE

先定義要管理的風險

選擇權策略不只是押漲跌，而是將方向、波動、期限與最大可承受損失組合成有明確代價的部位。單獨買一張 Call，和搭配持股的 Protective Put、限制報酬的 Covered Call，解決的問題不同。

以下所有示例使用同一標的、相同到期日、每股 USD 計價的歐式到期現金結算模型，先不計交易成本、股利、資金利息與提前履約。實際股票選擇權可能是美式並有提前指派風險，不能照搬簡化模型。

原則： 每加入一條選擇權腿，都應重新計算成本、最大虧損、最大獲利與到期損益兩平點。

02 / FOUR

四種常見組合與用途

策略 組合 主要取捨
Protective Put 持有標的 + 買 Put 花保費限制標的下跌損失
Covered Call 持有標的 + 賣 Call 收權利金，讓渡高於履約價的部分上漲
Bull Call Spread 買低 K Call + 賣高 K Call 降低淨成本，同時封頂潛在獲利
Collar 持有標的 + 買 Put + 賣 Call 用賣 Call 權利金抵銷部分保護成本，限制兩端

Short Straddle（同 K 同到期賣 Call + 賣 Put）看似可收兩筆 Premium，但沒有標的保護時，價格大幅波動會造成重大、甚至一側理論無上限的損失，不適合單純以「收權利金」概括。

03 / SPREAD

完整算例：Bull Call Spread

假設同一股票，買 K = USD 100 Call、付 Premium USD 7；同時賣 K = USD 110 Call、收 Premium USD 3。兩腿均為每股、同到期、假設，起初淨支付 7 − 3 = USD 4／股。

Spread 到期 Net P&L = max(Sₜ−100,0) − max(Sₜ−110,0) − 4
最大損失 = USD 4／股；最大獲利 = (110−100)−4 = USD 6／股
到期損益兩平點 = USD 104／股
假設到期 Sₜ 兩腿 Payoff 合計 扣淨權利金 USD 4 後的 Net P&L
USD 95 0 −USD 4／股
USD 104 4 USD 0／股
USD 120 10 +USD 6／股

相較單買 K100 Call，賣出 K110 Call 降低了淨成本，但也把最大收益封頂。這裡是到期每股淨額；若合約乘數 100 股，需再乘 100，尚未計費用。

04 / HEDGE

完整算例：Protective Put

假設你以 USD 100／股買入股票，同時支付 USD 3／股買進 K = USD 95 Put（同到期）。你的整體到期盈虧為：

Protective Put Net P&L = (Sₜ − 100) + max(95 − Sₜ,0) − 3
當 Sₜ ≤ 95，最大到期損失 = 95 − 100 − 3 = −USD 8／股

若 Sₜ = USD 80，股票損失 −20、Put Payoff +15、已付權利金 −3，合計 −USD 8／股；若 Sₜ = USD 120，股票收益 +20、Put 到期歸零，合計 +USD 17／股。保護有成本，Put 也不保護所有風險（例如流動性、信用與執行錯配）。

05 / TEST

辨識風險並練習

Q1：Bull Call Spread 的上下履約價是 100 / 110，淨 Debit = 4，最大利潤是多少？

價差寬度 10 扣淨權利金 4，最大到期淨利為 USD 6／股（假設，不計成本）。

Q2：Covered Call 是免費多賺一筆收入嗎？

不是。 你仍承擔持有標的下跌風險，而且出售 Call 讓渡一定程度的上漲潛能，可能有提前指派風險。
